ResuMate

An AI agent that tailors your resume to each job you apply for

  • Parses your existing resume into editable sections and pulls in context from your GitHub projects.
  • Rewrites the content against a job posting's requirements and saves each result as a reopenable Company / Role card.
  • Runs on Claude, or fully local with Ollama so your resume never leaves your machine and there's no API cost.

Python · FastAPI · SQLAlchemy · SQLite · Next.js · TypeScript · Claude / Ollama

FridgeVision

Take a picture of your fridge and ask where things are

  • Built for visually impaired users: photograph the fridge, then ask where an item is in plain English.
  • OpenCV detects the shelves and YOLO detects the items (over 90% detection accuracy), with an LLM handling the questions.
  • Flask backend chains upload, shelf segmentation and item detection into a saved fridge state that powers inventory tracking, shopping lists and recipes.

Python · Flask · OpenCV · YOLO · OpenAI API · JavaScript

DevLens

AI code review for GitHub pull requests

  • GitHub App that automatically reviews PRs when they're opened and posts inline comments on the diff.
  • RAG pipeline indexes the codebase so the review has context beyond the changed lines.
  • Reviews run through a Redis job queue so they never block webhook delivery, with per-org data isolation.

Python · FastAPI · Redis · LangChain · ChromaDB · OpenAI · Docker

PrivateMind

A fully offline AI "second brain"

  • Ingests your notes and PDFs and answers questions about them using a local LLM through Ollama, so no data leaves your machine.
  • Semantic search over everything you've added, plus SM-2 spaced repetition to resurface things you're about to forget.
  • Full-stack app deployed with Docker Compose, with an LLM-as-a-judge eval harness checking retrieval quality before each milestone.

Python · FastAPI · SQLAlchemy · ChromaDB · sentence-transformers · Ollama · React · TypeScript · Docker Compose

CoinCast

Time-series price forecasting for crypto

  • Fits Holt's exponential smoothing models to multi-year daily price history for 10+ cryptocurrencies.
  • FastAPI endpoint serves forecasts with confidence intervals over 7 to 30 day horizons.
  • React dashboard plots the forecast bands against what the price actually did, side by side across coins.

Python · FastAPI · statsmodels · Pandas · React · Chart.js · CoinGecko API
