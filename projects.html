Projects

Things I've built on my own time. Code for most of them is on github.

ResuMate

Tailors your resume to a specific job posting. Parses your resume, pulls context from your GitHub repos, and rewrites it against what the job is asking for. Runs on Claude, or fully local with Ollama if you don't want to pay for API calls.

FastAPI · Next.js · SQLite · Claude / Ollama

FridgeVision

Take a picture of your fridge and ask where stuff is. Made for visually impaired users. OpenCV finds the shelves, YOLO finds the items (~90% accurate), and an LLM handles the questions. Also does shopping lists and recipes.

Flask · OpenCV · YOLO · OpenAI API

DevLens

A GitHub app that reviews your pull requests and leaves inline comments. It indexes the repo with RAG so the comments actually know about the rest of the codebase.

FastAPI · Redis · LangChain · ChromaDB · GitHub Apps

PrivateMind

An offline "second brain." Feed it your notes and PDFs, ask questions about them, and it quizzes you with spaced repetition. Everything runs locally, nothing leaves your laptop.

FastAPI · ChromaDB · Ollama · React · Docker

CoinCast

Forecasts prices for 10+ cryptocurrencies with Holt's exponential smoothing, with a dashboard to compare the forecast bands against what actually happened. (Spoiler: crypto is hard to predict.)

FastAPI · statsmodels · React · Chart.js
